本版新增：

- 配置导入：支持 sing-box JSON、Clash YAML、分享链接/base64 文件，按内容自动识别格式，导入为独立分组；不支持的节点逐条回报
- 订阅导出：订阅卡可导出为 sing-box JSON / Clash YAML / 分享链接 / base64
- TUN 预热：启动即后台预建 TUN 服务与网卡，内核与规则集预读进缓存，首次开启 TUN 免冷等待
- 状态栏 Wi-Fi 共享按钮实时显示在线设备数
- 设置新增「隐藏核心控制台窗口」（改后需重启核心生效）

本版优化：

- TUN 关闭后删网卡从 5-6 秒缩短到 1 秒内
- DNS 接管随节点启动即时落位，TUN 服务空转 CPU 占用降低
- 联网检测更快出结果，托盘误报「无法连接 Internet」提前消除
- 更新下载进度实时推送，启动时按 PID 精确清理上次更新的残留文件
- 规则集按国家分目录存放，旧文件自动迁移

本版修复：

- TUN 启动报 "Cannot create a file when that file already exists / Element not found"：核心崩溃残留的坏网卡按本应用实例 ID 精确清除
- 不再误删其他 VPN 客户端的 wintun 网卡
- 主题等纯界面设置不再触发核心重启
