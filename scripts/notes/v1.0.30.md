本版修复：

- 仓库改名后更新检查失效：GitHub 对旧地址先回一次仓库级跳转，`/releases/latest` 的跳转不再直接带 tag，检查退化成走限流 API。现在跟随这次跳转；默认仓库、问题反馈与发行脚本也改为新地址
- 节点名正好是 `proxy`、`direct`、`bypass` 或 `dns-*` 时，保留名的首个占用没有被拦住：选择器或直连出站出现重名，核心拒绝整份配置。现在第一个重名也会加后缀
- 分享链接里写 `allowInsecure=0` / `insecure=false` 时被当成开启，节点悄悄跳过证书校验。现在按值解析，只有 `1` / `true` / `yes` / `on` 才算开启
- TUN 授权弹窗期间再次点启动，取消上一次授权会把新启动的节点停掉。现在旧的待定结果发现已有新启动就直接退出，不再停核心、不再回滚、不再清掉「等待授权」
- 设置面板的端口与 MTU 输入后直接按 Esc 或点面板外关闭会丢值：现在关闭前先让焦点离开，草稿随之提交
- 设置面板的焦点陷阱把离屏卡片上的按钮也算了进去，Tab 仍能走到表格背后的行；字号滑块的方向键同时翻设置页；热键恢复重试成功却弹「恢复失败」；热键捕获期间的第二次 Esc 会关掉面板——一并修正
- 日志面板按「错误 / 警告」筛选且没有匹配行时是一片空白，现在给出「无匹配」；日志级别菜单的 Esc 只关菜单；打开面板时的缓冲读取不再覆盖期间到达的实时行
- 节点右键菜单较高时，滚动它自身会把它关掉；订阅抽屉的「导出配置」按钮无法再次点击关闭
- 复制出口信息时经纬度 0 被当作空值丢弃；局域网地址的定时读取可能在切换后写回旧端点
- 对话框焦点落到 body 后 Tab 可以离开对话框；标题栏搜索框按 Esc 会连带关掉通过热键打开的面板

其他：

- 双进程 TUN 下主核心没有 tun 入站，FakeDNS 一直没有生效。本版把该开关禁用并在提示中说明，旧配置仍可读取
