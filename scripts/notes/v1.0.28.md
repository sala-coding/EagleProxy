本版新增：

- 直连规则的国家预设补齐同一套通用项：四面国旗（中国 / 俄罗斯 / 美国 / 伊朗）都带上内网、Apple、微软，再加 `domain:local`（mDNS 与 `.local` 主机名）和 `domain:home.arpa`（部分路由器的家庭域名）。美国上游没有国家级域名表，仍只带通用项；伊朗预设此前缺失，现在也有（`geosite:category-ir` + `geoip:ir`）
