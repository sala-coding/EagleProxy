本版新增：

- 系统代理绕过列表（ProxyOverride）出厂默认值扩展：除本机回环与内网网段外，内置知乎、京东、讯飞语音 API 等国内直连域名。开启系统代理时自动写入，无需手动配置；设置中「代理绕过」留空时生效，填写后以用户值优先

- 启动后自动检查更新：发现新版本时自动打开「关于」窗口并显示新版本信息栏，未发现则静默
- 更新检查不再消耗 GitHub API 配额：常规检查由发布页重定向直接取版本号，下载地址一并推导；仅「含预发布」等场景才走 API，且 403 限流后退避至配额恢复
