本版更新：

- 修复 sing-box 1.14+ 上远程规则集未声明 HTTP 客户端导致核心 FATAL 退出（表现为「核心反复退出」）
- 修复切换语言后设置面板等位置仍有旧语言文本残留
- 自定义主题可读性：正文与次要文字提亮；选中态统一为「副题色底 + 强调色标记」，胶囊、路由模式卡、DNS 行不再看不清
- 日志级别下拉改为自绘菜单，悬停使用主题悬停色，不再出现系统白色高亮
- 设置 → 核心路径改为下拉框：自动监控内核所在目录，可直接点选切换

- 局域网共享：有设备在线时图标变绿并呼吸，角标显示设备数
- 状态栏与左侧导航图标位置微调
